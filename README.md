# RawsoniEQ Signature by TAMORIX

Precision in every frequency. Character in every sound.

## About

RawsoniEQ Signature is a browser-based audio equalizer developed under the TAMORIX brand.

## Features

- 10, 20 and 30-band Equalizer
- Real-time audio processing
- Signature and Flat presets
- Custom preset saving
- WAV export
- MP3 export
- FLAC export
- Spatial audio export option
- Premium emerald green and silver interface

## Technologies

- HTML5
- CSS3
- JavaScript
- Web Audio API
- Python
